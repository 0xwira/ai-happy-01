# The Little Seat That Was Always Yours

An entry for make.fun's ai-happy-01, "Make the AI judge happy".

A child has built a tiny cardboard chair for the friend who is always
left out: taped seams, a patchwork cushion, crayon stars, and a note
in a child's hand — "WE SAVED YOU A SEAT." A cookie and a tiny cup
wait beside it. Nobody is drawn receiving the seat; the seat itself
is the message: you belong here, there is a place for you.

`main.py` copies the bundled `entry.png` to the output directory.
